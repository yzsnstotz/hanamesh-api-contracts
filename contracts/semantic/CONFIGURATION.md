README null/cached behavior is retained because it is part of the published provider semantics. When default fetching cannot supply a README, the module's diagnostic callback now receives a reason before sync retains cachedReadme. HTTP/provider rejection bodies are explicitly canceled when unconsumed. Diagnostics contain only reason codes, counts, status, timeout and byte limits, never key, query, headers, URL, response body or arbitrary upstream error message. Supply `diagnostic` on module and provider options to collect them; plain caller errors still propagate under their existing identity.

Voyage still retries 429/5xx, not transport/timeouts. JEV still retries transport errors and 429/529, honoring a positive numeric Retry-After; it retains its original response parser and candidate/schema/policy checks. These are preserved policies, not claims that retries solve an upstream fault. All new provider tests use injected fetch/sleep and synthetic values, never credentials or paid services.

Additive configuration declarations are module-owned. Formal v0.18.0 original constructors/factories remain structurally assignable and all prior positive/negative consumer assertions remain. PM Q81 authorizes these provider-owned additions and the current-row read port; APIC21 follows the actual main source once, without this provider waiting on itself. Complete read scope/pagination/error definitions are in EMBEDDING-FACTS.md; see Q61-REVIEW.md. No second contract definition is maintained here.
